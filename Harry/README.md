# Hogwarts Letter Experience

## Run in VS Code

Open this folder in VS Code, then run:

```powershell
npm install
npm run dev
```

## Flow

1. Hogwarts night arrival scene.
2. Enter your name.
3. Click **Open My Letter**.
4. The acceptance letter appears directly — there is no envelope/loading/blank-parchment stage.
5. Your name appears in the letter as **Dear [Name],**.
